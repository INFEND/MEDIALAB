# MediaLAB 1.3.98

[+] Исправлено автоматическое продолжение OTA-загрузки, когда HTTPS-сервер досрочно завершает тело ответа HTTP 206. Полученные байты сохраняются, а оставшаяся часть запрашивается следующим Range-запросом без ручного нажатия «Повторить».
[+] Сохранён предел 128 последовательных HTTP-ответов и защита от ответов без новых байтов.
[=] Неполный HTTP 200 по-прежнему считается ошибкой, чтобы не зациклить загрузку с нуля.
[=] SHA-256, сертификат APK, ограничения HTTPS и внешняя докачка FFmpeg не изменены.
