[=] OTA: исправлена докачка APK при допустимых частичных ответах HTTP 206. Теперь корректно принимается любой валидный диапазон, начинающийся с ожидаемого байта и соответствующий полному размеру.
[+] Проверка Content-Range защищает от неверного начала, общего размера, переполнения чисел и некорректных заголовков. Добавлен JVM-регрессионный тест в GitHub Actions.
[=] Сохранены HTTPS-ограничения, SHA-256, проверка сертификата, штатный установщик, единое тематическое окно OTA и накопительная история.
[=] Нативные библиотеки остаются отдельной докачкой. Лёгкий APK не содержит FFmpeg .so.
