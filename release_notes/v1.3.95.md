# MediaLAB 1.3.95

- Проверка HTTP 206 усилена: объявленный Content-Length должен точно соответствовать диапазону Content-Range перед дозаписью APK.
- Ответы с противоречивыми заголовками отклоняются до изменения частично загруженного файла.
- HTTPS, SHA-256, сверка сертификата, штатный установщик и отдельная докачка ARM64-библиотек сохранены.

Проверка сборки, подписи и опубликованного update.json выполняется в GitHub Actions; до успешного CI релиз не считается подтверждённым.
