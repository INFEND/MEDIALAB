# MediaLAB v1.2.7

Android Java проект, ориентирован на Code on the Go / Gradle 9.6.1 / AGP из Code on the Go.

## Установка v1.2.7 (чистая папка MediaLAB)

1. Переименуйте прежнюю папку `Download/MediaLAB` в `Download/MediaLAB_backup`.
2. Распакуйте этот ZIP, чтобы новая корневая папка была `Download/MediaLAB`.
3. Скопируйте **только** файл `ffmpeg-kit-full-8.1.9.aar` из `MediaLAB_backup/app/libs` в `MediaLAB/app/libs`.
4. Откройте новый проект в Code on the Go, выполните `:app:assembleDebug`.
5. В консоли должно появиться: `MediaLAB 1.2.7: local FFmpegKit AAR from app/libs`.

Версия сохраняет весь рабочий функционал v1.2.6. Обновлён только визуальный стиль. Скрипты не требуются.

## Сохранённые функции v1.2.6: быстрый размер и умный выбор

- Размер оценивается **в два этапа**. Сразу показывается ориентировочный размер по выбранному качеству, затем он уточняется по данным длительности/разрешения, полученным через SAF URI без копирования в кэш.
- Параллельно создаётся настоящий образец; уже после первого готового фрагмента прогноз меняется на измеренный по этому фрагменту, далее уточняется по всем сценам. Для изображений окончательный образец содержит полную картинку.
- Пока образцы готовятся, в карточке показывается индикация загрузки, подробный этап и процент FFmpeg. Значения не обещают абсолютно точный размер: сложность видеосцен, переменный битрейт и наличие аудиодорожек влияют на результат.
- При выборе видео на вкладке изображений приложение переходит на вкладку видео. Если открыта вкладка «Извлечь звук» и выбран видеоролик, остаётся там.
- При смешанном наборе появляется диалог выбора группы (сколько фото, видео, аудио). Программа не пытается конвертировать несовместимые типы одной командой. Нераспознанные расширения выдаются предупреждением.

## Новый синхронный видеопредпросмотр

- После выбора качества FFmpeg подготавливает до пяти коротких участков видео.
- Сжатые образцы, соответствующие текущим настройкам, служат также для приблизительной оценки размера будущего видео.
- Для каждого отрезка дополнительно кодируется **единый** сравнительный MP4: слева оригинал, справа сжатый фрагмент, их кадры нормализованы по временной шкале FFmpeg.
- Встроенный экран всегда запускает синхронное сравнение. Первое положение шторки 50%. Движение разделителя не запускает повторное декодирование или FFmpeg.
- Экран отображает один видеопоток на GPU через SurfaceTexture/OpenGL ES 2.0 и один системный MediaPlayer. Звуковая дорожка берётся из сжатого образца.
- Для изображений сравнение статично: кадры размещаются в одной прямоугольной области с сохранением пропорций.
- **Ограничение:** чтобы показать два варианта одновременно, сравнительный видеофайл повторно кодируется в MPEG-4. Это может слегка снижать качество обеих половин по сравнению с исходными файлами. Сжатый образец для оценки размера от повторного кодирования не меняется.

## Интерфейс v1.2.7 (стиль QR LINK)
- Тёмная, AMOLED и светлая темы; скруглённые панели и кнопки, новые цвета карточек и активных элементов.
- Шестерёнка справа наверху открывает оформленные под текущую тему настройки.
- Пять раскрывающихся категорий, все изначально закрыты: Тема, Акцент, Производительность, Предпросмотр, Система и диагностика.
- Плавное раскрытие ~245 мс, закрытие ~210 мс; Ripple и анимации нажатий.
- 24 готовых акцента с названиями. Первые 7 цветов сохранили прежние индексы настроек. Выбранный цвет подписан своим цветом.
- Обновлены вкладки и карточки; полноэкранный плеер и шторка используют выбранный акцент.
- Прогресс фоновой конвертации разделён на текущий файл и всю очередь.
- Цвета/режимы сохраняются между запусками.

Оформление создано по подтверждённым характеристикам QR LINK. Получить исходный ZIP QR LINK v0.3.7 из Библиотеки для точного копирования ресурсов не удалось, поэтому это стилистическая адаптация, а не побайтовая копия.

## FFmpegKit AAR

Требуется `MediaLAB/app/libs/ffmpeg-kit-full-8.1.9.aar` (~31 МБ). ZIP не содержит бинарник. Официальный файл релиза:
https://github.com/ffmpegkit-maintained/ffmpeg/releases/download/v8.1.9-lts-android/ffmpeg-kit-full-8.1.9-arm64-v8a-x86_64.aar

При отсутствии AAR сборка намеренно остановится с понятной ошибкой. Не разархивируйте AAR: файл должен лежать в `app/libs` целиком.

## Реальность проверки
Проведена синтаксическая проверка восьми Java-файлов через JavacTask.parse, XML-проверка и сверка ссылок на все 24 Android-стиля, проверка структуры ZIP. Функции конвертации сохранены из v1.2.6 без изменений. Полная Android-сборка и работа на устройстве не подтверждены.
